## ЧАСТИНА I. Робота в системі (для користувача)

### 1. Вхід до системи
1. Відкрийте посилання на веб-додаток у браузері.
2. Введіть пароль доступу та натисніть **Увійти**.
3. Якщо сайтом не користувалися кілька днів і з’явився екран очікування (*«Your app is in the oven...»*), зачекайте **15–20 секунд** — система запуститься автоматично.

### 2. Завантаження Excel-звітів (`📤 Завантаження Excel`)
Завантажуйте **деталізовані** файли (з портовими операторами):
- **`23-м ... з ПО ... .xlsx`** — номенклатура вантажів (`Експорт`, `Імпорт`, `Транзит`, `Внутрішнє сполучення`).
- **`25-вод ... з ПО ... .xlsx`** — кількість оброблених суден та причини падіння/проведена робота.

> ⚠️ Файли **«без ПО»** завантажувати не потрібно — усі зведені підсумки по портах система рахує автоматично.

**Порядок дій:**
1. Перейдіть у розділ **`📤 Завантаження Excel`**.
2. **Правило галочки *«Імпортувати також колонку минулого року»*:**
   - **Ставте галочку**, якщо завантажуєте файли поточного року (напр. 2026 р.), а даних за минулий рік (2025 р.) у базі ще немає.
   - **Знімайте галочку**, якщо довантажуєте старіші архівні місяці окремо (або завантажуйте архів строго від найстарішого місяця до найновішого).
3. Перетягніть один або одразу пачку файлів `.xlsx` і натисніть **«🚀 Обробити та зберегти в хмарну базу»**.
4. **Повторне завантаження:** якщо завантажити виправлений файл за вже існуючий місяць, система видалить старі цифри **тільки за цей місяць** і запише нові (без дублів).
5. **Жовті попередження:** автоматичний аудит звіряє суму вантажів по оператору з рядком `ВСЬОГО ВАНТАЖІВ` у файлі.

### 3. Довідник операторів і коментарі (`📝 Причини та довідники`)
1. Відкрийте вкладку **`Налаштування операторів`**.
2. Державних операторів система визначає автоматично. Для приватних із позначкою `Не визначено` один раз оберіть у колонці **«Тип причалу»**: *`Приватний на причалах АМПУ`* або *`Приватний на власних причалах`*.
3. За потреби об’єднайте різні варіанти написання однієї компанії в колонці **«Уніфікована назва»** і натисніть **«💾 Зберегти довідник»**.
4. На вкладці **`Коментарі з звітів (25-вод)`** можна переглядати очищені пояснення причин падіння по портах.

### 4. Інтерактивний дашборд (`📊 Дашборд та KPI`)
- **Фільтри:** можна обирати один місяць або одразу кілька (квартал/рік), фільтрувати за кластером (`Дунайський` / `Велика Одеса`), портами та напрямками.
- **KPI:**
  - `Вантажообіг, тис. т` (тільки вагові вантажі; контейнери в `TEU` винесені в окрему картку).
  - `YoY %` — відхилення до аналогічного місяця минулого року.
  - `Середня партія` = `Вантажообіг / Кількість суден`.
- **Вкладки:** *Огляд портів* (стовпці, структура власності, каскад YoY), *Динаміка та сезонність* (лінійний тренд і теплова карта `Порт × Місяць`), *Оператори та вантажі* (рейтинг зі смужками прогресу та Treemap).

### 5. Вертикальна та горизонтальна фільтрація (`🧮 Конструктор матриць`)
1. Оберіть **Одиницю виміру** (`тис. тонн`, `TEU` або `шт`).
2. Задайте фільтри (**Періоди**, **Напрямки**, **Порти**, **Оператори**, **Вантажі**).
3. Налаштуйте **Рядки** (вертикальний зріз) та **Стовпці** (горизонтальний зріз), оберіть показник (`Обсяг`, `Різниця YoY`, `Частка %`).
4. Натисніть **«📥 Завантажити матрицю в Excel (.xlsx)»** або **«📄 Завантажити матрицю в PDF»** *(у PDF вміщується до 10 колонок)*.

### 6. Професійні PDF-звіти (`📄 PDF-звіти (Аудит)`)
1. **Виконавчий звіт:** KPI, автоматичні висновки, графіки, зведена таблиця по портах.
2. **Аудит операторів:** індекси концентрації **CR3 / CR5** та **HHI** (`<1500` — конкурентний ринок, `1500–2500` — помірна концентрація, `>2500` — висока концентрація), реєстр операторів і причини падіння.
3. **Номенклатурний аудит:** розріз вантажів, `TEU/шт`, перевірка якості даних (нерозшифровані хлібні вантажі, некласифіковані причали).

## ЧАСТИНА II. Супровід та адміністрування (для адміністратора)

### 1. Щотижнева профілактика «засинання» бази Supabase
На безкоштовному тарифі Supabase ставить базу на паузу, якщо до неї **7 днів поспіль** не було жодного звернення.
- **Профілактика:** відкривайте веб-додаток хоча б **1 раз на 5–6 днів**.
- **Якщо база заснула:** зайдіть у кабінет [supabase.com](https://supabase.com) → ваш проєкт → натисніть **Restore project** (зачекайте 1–2 хв до статусу *Active*) → у меню Streamlit натисніть **`⋮` → Reboot app**.

### 2. Контроль обсягу хмари та резервні копії
- **Обсяг БД:** перевіряється у **Supabase → Project Settings → Usage** (ліміт **500 МБ**; 1 місяць статистики займає ~0,3–0,5 МБ, тобто ресурсу вистачить на десятки років).
- **Резервні копії:** раз на квартал зберігайте папку з вихідними Excel-файлами або експортуйте таблиці у **Supabase → Table Editor → Export to CSV**.

### 3. Керування паролями
- **Зміна пароля входу на сайт:** у Streamlit Cloud відкрийте **`⋮` → Settings → Secrets**, змініть `APP_PASSWORD = "НовийПароль"`, натисніть **Save** та **`⋮` → Reboot app**.
- **Зміна пароля БД:** у **Supabase → Project Settings → Database → Reset database password** задайте новий пароль (тільки латинські літери та цифри без `@`, `#`, `/`), оновіть його у `DATABASE_URL` в Streamlit **Secrets** → **Save** → **`⋮` → Reboot app**.
