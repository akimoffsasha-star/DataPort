# 📘 Система портової аналітики: Інструкція

## Як влаштована система
| Складова | Де розміщена | Призначення |
| :--- | :--- | :--- |
| **Веб-інтерфейс** | **Streamlit Community Cloud** | Фільтри, дашборди, конструктор матриць, генерація Excel і PDF. |
| **База даних** | **Supabase (PostgreSQL)** | Зберігає всі завантажені місяці та довідники (ліміт Free — **500 МБ**). |
| **Код і планувальник** | **GitHub (приватний репозиторій)** | Файли системи та автопінг `keep_alive.yml` для підтримки бази онлайн. |

## ЧАСТИНА I. Робота в системі (для користувача)

### 1. Вхід до системи
1. Відкрийте посилання на веб-додаток у браузері.
2. Введіть пароль доступу та натисніть **Увійти**.
3. Якщо сайтом не користувалися кілька днів і з’явився екран очікування (*«Your app is in the oven...»*), зачекайте **15–20 секунд** — система запуститься автоматично.

### 2. Завантаження Excel-звітів (`📤 Завантаження Excel`)
Завантажуйте **деталізовані** файли (з портовими операторами):
- **`23-м ... з ПО ... .xlsx`** — номенклатура вантажів (`Експорт`, `Імпорт`, `Транзит`, `Внутрішнє сполучення`).
- **`25-вод ... з ПО ... .xlsx`** — кількість оброблених суден та причини падіння/проведена робота.

> ⚠️ Файли **«без ПО»** завантажувати не потрібно — усі зведені підсумки по портах система рахує автоматично.

**Порядок дій:**
1. Перейдіть у розділ **`📤 Завантаження Excel`**.
2. **Правило галочки *«Імпортувати також колонку минулого року»*:**
   - **Ставте галочку**, якщо завантажуєте файли поточного року (напр. 2026 р.), а даних за минулий рік (2025 р.) у базі ще немає.
   - **Знімайте галочку**, якщо довантажуєте старіші архівні місяці окремо (або завантажуйте архів строго від найстарішого місяця до найновішого).
3. Перетягніть один або одразу пачку файлів `.xlsx` і натисніть **«🚀 Обробити та зберегти в хмарну базу»**.
4. **Повторне завантаження:** якщо завантажити виправлений файл за вже існуючий місяць, система автоматично видалить старі дані **тільки за цей місяць** і запише нові (без дублів).
5. **Жовті попередження:** автоматичний аудит звіряє суму вантажів по оператору з рядком `ВСЬОГО ВАНТАЖІВ` у файлі.

### 3. Довідники, коментарі та керування місяцями (`📝 Причини та довідники`)
1. **Коментарі з звітів (25-вод):** очищені від сміттєвих символів пояснення причин падіння вантажообігу по портах та операторах.
2. **Налаштування операторів:** державні оператори визначаються автоматично. Для приватних із позначкою `Не визначено` один раз оберіть у колонці **«Тип причалу»**: *`Приватний на причалах АМПУ`* або *`Приватний на власних причалах`*, за потреби об’єднайте дублі назв і натисніть **«💾 Зберегти довідник»**.
3. **🗑️ Керування місяцями:** показує таблицю всіх завантажених періодів (кількість рядків, тоннаж, судна, коментарі) та дозволяє у 2 кліки **видалити окремий помилковий місяць** або виконати повне скидання даних прямо з сайту, без заходу в базу даних.

### 4. Інтерактивний дашборд (`📊 Дашборд та KPI`)
- **Фільтри:** можна обирати один місяць або одразу кілька (квартал/рік), фільтрувати за кластером (`Дунайський` / `Велика Одеса`), портами та напрямками.
- **KPI:**
  - `Вантажообіг, тис. т` (тільки вагові вантажі; контейнери в `TEU` винесені в окрему картку).
  - `YoY %` — відхилення до аналогічного місяця минулого року.
  - `Середня партія` = `Вантажообіг / Кількість суден`.
- **Вкладки:** *Огляд портів* (стовпці, структура власності, каскад YoY), *Динаміка та сезонність* (лінійний тренд і теплова карта `Порт × Місяць`), *Оператори та вантажі* (рейтинг зі смужками прогресу та Treemap).

### 5. Вертикальна та горизонтальна фільтрація (`🧮 Конструктор матриць`)
1. Оберіть **Одиницю виміру** (`тис. тонн`, `TEU` або `шт`).
2. Задайте фільтри (**Періоди**, **Напрямки**, **Порти**, **Оператори**, **Вантажі**).
3. Налаштуйте **Рядки** (вертикальний зріз) та **Стовпці** (горизонтальний зріз), оберіть показник (`Обсяг`, `Різниця YoY`, `Частка %`).
4. Натисніть **«📥 Завантажити матрицю в Excel (.xlsx)»** або **«📄 Завантажити матрицю в PDF»** *(у PDF вміщується до 10 колонок)*.

### 6. Професійні PDF-звіти (`📄 PDF-звіти (Аудит)`)
1. **Виконавчий звіт:** KPI, автоматичні висновки, графіки, зведена таблиця по портах.
2. **Аудит операторів:** індекси концентрації **CR3 / CR5** та **HHI** (`<1500` — конкурентний ринок, `1500–2500` — помірна концентрація, `>2500` — висока концентрація), реєстр операторів і причини падіння.
3. **Номенклатурний аудит:** розріз вантажів, `TEU/шт`, перевірка якості даних (нерозшифровані хлібні вантажі, некласифіковані причали).

## ЧАСТИНА II. Супровід та адміністрування (для адміністратора)

### 1. Автономна робота бази даних (без втручань)
- **Автопінг Supabase:** робочий процес GitHub Actions (`.github/workflows/keep_alive.yml`) кожні 4 дні автоматично виконує легкий запит до бази, тому вона **не засинає** навіть під час тривалих перерв у роботі.
- *(Примітка: якщо в репозиторій не вносилися зміни коду понад 60 днів, GitHub може надіслати повідомлення про призупинення розкладу — достатньо 1 кліку «Enable workflow» на вкладці Actions).*
- **Видалення або перезавантаження місяців:** виконується прямо на сайті в розділі **`📝 Причини та довідники → 🗑️ Керування місяцями`**, ручні SQL-запити більше не потрібні.

### 2. Контроль обсягу хмари та резервні копії
- **Обсяг БД:** перевіряється у **Supabase → Project Settings → Usage** (ліміт **500 МБ**; 1 місяць статистики займає ~0,3–0,5 МБ, тобто ресурсу вистачить на десятки років).
- **Резервні копії:** раз на квартал зберігайте папку з вихідними Excel-файлами або експортуйте таблиці у **Supabase → Table Editor → Export to CSV**.

### 3. Керування паролями
- **Зміна пароля входу на сайт:** у Streamlit Cloud відкрийте **`⋮` → Settings → Secrets**, змініть `APP_PASSWORD = "НовийПароль"`, натисніть **Save** та **`⋮` → Reboot app**.
- **Зміна пароля БД:** у **Supabase → Project Settings → Database → Reset database password** задайте новий пароль (тільки латинські літери та цифри без `@`, `#`, `/`), оновіть його в `DATABASE_URL` у **двох місцях**: у Streamlit **Secrets** (плюс `Reboot app`) та в **GitHub → Settings → Secrets → Actions** (для автопінгу).

### 4. Додавання нових вантажів або портів у код
- **Новий вид вантажу в Excel:** додайте рядок у словник `CARGO_META` у файлі `etl_parser.py` на GitHub.
- **Новий порт:** додайте умову у функцію `normalize_port_name()` у `etl_parser.py` та рядок у таблицю `dim_ports` у Supabase.

## ЧАСТИНА III. Швидка діагностика помилок

| Симптом | Ймовірна причина | Рішення |
| :--- | :--- | :--- |
| Дані в базі оновилися, а на графіках ще старі | Діє 5-хвилинний кеш (`ttl=300`) | Натисніть у правому кутку **`⋮` → Clear cache → Rerun**. |
| Помилка `OperationalError` / не підключається до БД | База Supabase заснула (після 60+ днів паузи Actions) або змінився пароль БД | Відновіть проєкт у Supabase (**Restore**), перевірте `DATABASE_URL` і зробіть **`⋮` → Reboot app**. |
| У PDF-матриці не помістилися всі стовпці | Обрано понад 10 колонок по горизонталі | Вивантажуйте широкі матриці кнопкою **«Завантажити матрицю в Excel (.xlsx)»**. |
| На діаграмі власності є частка «Не визначено» | З’явилися нові приватні оператори | Проставте їм тип причалу в **«📝 Причини та довідники»** і натисніть **Зберегти**. |
